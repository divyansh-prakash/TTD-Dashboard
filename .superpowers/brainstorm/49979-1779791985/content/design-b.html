What gets built

  • Backend: New repo function getHealthyCategoryTotals queries success=1 rows, grouped by matchedby, for the platform's URLs. The service cross-references: a category is "healthy" only if it has zero rows in success=0. Returns healthyGroups[] alongside the existing matchedByGroups[].
  • Frontend model: Add healthyGroups?: HealthyGroup[] to PlatformGroup.
  • Frontend template: After the existing sub-accordion list, render a "Healthy — 100% serving" divider row + one read-only green row per healthy group (same grid columns, no chevron, no expand).
  • Only shown when the card is expanded and healthyGroups has entries. Nothing changes for collapsed cards.
